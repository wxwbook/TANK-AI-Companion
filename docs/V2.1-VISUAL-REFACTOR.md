# TANK-AI-Companion V2.1 · 视觉重构说明

## 本轮目标
将 V2.0 的自适应卡片仪表盘调整为 TANK-AI-Office 指挥中心布局：左侧导航、顶部状态栏、中央办公室场景、团队 KPI、任务/Agent 工作区，以及右侧大肥鱼总监信息栏。

## 已完成
- 重做 `apps/office/index.html` 的整体布局和视觉样式。
- 增加左侧分区导航与移动端横向导航。
- 增加中央等距办公室场景、Agent 工位状态样式、KPI 数据条。
- 增加右侧大肥鱼总监栏、状态和快捷操作。
- 将任务、审批、集成、NAS、插件、工坊、人格、记忆、日记、语音、聊天等现有功能放入统一工作区。
- 保留 `apps/office/app.js` 与 API 调用逻辑，不改变后端接口和权限流程。

## 重要边界
当前办公室场景仍是 CSS 等距（2.5D）表现，不是 Three.js/WebGL 真 3D，也没有 GLB 模型、骨骼动画或可旋转漫游场景。页面中的 Agent 状态来自现有 `/api/overview` 数据，但角色仍使用现有 Emoji 图标。要达到最终视觉基准，下一阶段需要引入 Three.js / React Three Fiber（或原生 Three.js）、正式的 3D 场景资产和角色动画系统。
